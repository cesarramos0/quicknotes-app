# Retrospectiva: QuickNotes

## ¿Qué aprendí durante el proyecto?

Este proyecto me ha permitido entender por primera vez cómo se construye una aplicación web completa de principio a fin. Lo más valioso ha sido comprender la estructura completa de React: cómo se organizan los archivos, qué responsabilidad tiene cada carpeta y cómo se conectan los componentes, el contexto, las rutas y la capa de red entre sí.

También aprendí a desplegar un backend en un servidor real con Render, algo que no había hecho antes. Ver cómo el frontend en Vercel se comunica con el backend en Render a través de una URL pública fue uno de los momentos más satisfactorios del proyecto.

---

## ¿Qué fue lo más difícil?

Lo que más me costó fue entender la utilidad de cada archivo y cómo se conectaban todos entre sí. Al principio era difícil ver por qué había tantos archivos separados para algo que parecía simple. Con el tiempo fui entendiendo que cada capa tiene una responsabilidad concreta: los tipos definen el contrato de datos, el cliente de API centraliza las llamadas HTTP, el contexto gestiona el estado global, y los componentes solo se preocupan de renderizar y reaccionar a las acciones del usuario.

---

## ¿Qué fue lo que más gustó?

Descubrir Carbon Design System de IBM fue una grata sorpresa. Tener componentes ya diseñados y listos para usar (botones, inputs, tarjetas, menús) permitió centrarse en la lógica de la aplicación sin perder tiempo en CSS. Su integración con React fue sencilla y el resultado visual es profesional desde el primer momento.

---

## ¿Cómo usé la IA durante el desarrollo?

La IA fue una herramienta clave a lo largo de todo el proyecto. Me ayudó a conectar todas las piezas de forma precisa, especialmente en los momentos donde no era evidente cómo debían comunicarse el frontend y el backend. También resolvió todas las dudas que fueron surgiendo sobre la marcha, desde errores de TypeScript hasta problemas de configuración en el despliegue, lo que permitió mantener el ritmo sin quedarme bloqueado.

---

## ¿Qué haría diferente?

Si empezara desde cero, dedicaría más tiempo al inicio a pensar cómo quiero que sea la página y qué componentes necesito antes de escribir la primera línea de código. Tener un diseño o boceto previo de la interfaz habría facilitado la creación de los componentes y evitado alguna decisión tomada sobre la marcha.

---

## Reflexión final

QuickNotes ha sido mi primer proyecto fullstack real. He pasado de entender React de forma teórica a construir una aplicación con frontend, backend, integración con una API de IA y despliegue en producción. Cada parte del proyecto tiene sentido dentro del conjunto, y eso es algo que solo se aprende haciéndolo.
