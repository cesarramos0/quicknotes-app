# QuickNotes App

Aplicación fullstack para gestionar notas con mejoras mediante IA.

## 🚀 Demo

- Vercel: [Web](https://quicknotes-app-theta.vercel.app/)

## Stack
- Frontend: React + TypeScript + Tailwind CSS
- Backend: Node.js + Express
- IA: Groq API
